What the data told usO que o dado nos contou

Five things that changed the plan the moment we actually opened the files. This is the part worth talking about — it shows you looked. Cinco coisas que mudaram o plano no momento em que abrimos os arquivos de verdade. Essa é a parte que vale contar — mostra que você olhou.

Silent trapArmadilha silenciosa

One ID, two tournamentsUm ID, dois torneios

All 30 editions use the same WC-<year> pattern. WC-1991 is the women's tournament; WC-1994 is the men's. Only the tournament name tells them apart, the years never overlap, and the ID is unique — so grouping by ID blends both competitions and nothing errors. As 30 edições usam o mesmo padrão WC-<ano>. WC-1991 é a Copa feminina; WC-1994, a masculina. Só o nome distingue, os anos nunca se sobrepõem e o ID é único — então agrupar por ID mistura as duas competições e nada dá erro.

Half a fieldMeio campo

Attendance exists — but only for 2026Público existe — só que só em 2026

The plan promised attendance in the map popups. Fjelstul has 36 columns and none is attendance. Wikipedia has it per match, so 2026 came with 6,810,966 — and 1930–2022 still has none. One column, two different worlds. Resolved on 08/08 by dropping it from the features entirely. O plano prometia público nos popups do mapa. O Fjelstul tem 36 colunas e nenhuma é público. A Wikipédia tem, por partida, então 2026 veio com 6.810.966 — e 1930–2022 continua sem nada. Uma coluna, dois mundos diferentes. Resolvido em 08/08 tirando o público das features.

213 cities, not “a few”213 cidades, não “poucas”

The plan assumed venues could be geocoded by hand. Across both sources it's 247 stadiums in 213 cities — four venues recur, the Azteca among them, having also hosted 1970 and 1986.
